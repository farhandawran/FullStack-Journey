# Farhan Ahmad - Portfolio Website

Assignment 1 for CSC 337 (Web Programming Languages), Iqra University, H-9 Campus, Islamabad.

A simple 4-page portfolio website built with only HTML and CSS (no JavaScript, no templates).

## Pages

| File | What it shows |
| --- | --- |
| index.html | Home page with introduction |
| hobbies.html | Lists, game descriptions and two tables |
| media.html | Social media posts, images and 5 YouTube videos |
| contact.html | Contact details, Google Map, friends list and a form |

## Folder structure

```
index.html
hobbies.html
media.html
contact.html
css/style.css
images/profile.png
images/favicon.png
```

## How it was published

1. Pushed all files to the `main` branch of this repository.
2. Settings -> Pages -> Branch: `main`, Folder: `/ (root)`.
